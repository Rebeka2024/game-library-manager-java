# 🎮 Game Library Manager (Java)
A Java application that manages a personal video game collection using object-oriented programming concepts.


## Overview

A Java console application that allows users to manage a personal video game collection.

Users can add games, view their collection, and search for specific titles.

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- Scanner Input

## Features

- Add games
- View game library
- Search games
- Store game information using objects

## Java Concepts Demonstrated

- Classes and objects
- Constructors
- Encapsulation
- Methods
- ArrayLists
- Conditional logic
- User input handling
